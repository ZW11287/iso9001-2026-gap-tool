# ISO 9001:2026 Gap Analysis Tool

Excel workbook for clause-by-clause gap analysis across the full ISO 9001:2026 standard — with compliance score tracking and prioritized remediation planning.

## What This Does

Maps every requirement from ISO 9001:2026 against your organization's current state: identify compliance gaps by clause, track readiness scores, and generate an ordered action plan.

## Usage Flow

1. **Assess** — Open `Gap_Analysis`. For each clause of ISO 9001:2026, mark your organization's current status in the assessment columns.
2. **Read Dashboard** — View `Readiness_Score_Dashboard` for aggregate compliance scores and color-coded indicators per major section (Context, Leadership, Planning, Support, Operation, Performance Evaluation, Improvement).
3. **Export Action Plan** — The linked `Action_Plan` sheet populates automatically: items ordered by Priority × Risk weight with suggested owners and deadlines.

## Key Dates

- **16 Sep 2026**: ISO 9001:2026 published
- **30 Sep 2029**: All certified organizations must have transitioned from ISO 9001:2015

*This tool supports general gap analysis only and is not a substitute for formal certification-body assessment.*
